# 开源许可范围

本项目原创 HTML、CSS、JavaScript、构建脚本与文档采用 [MIT 许可证](LICENSE)，保留其中已有的第三方版权声明。

图片与音频资源不自动适用代码的 MIT 许可：
- `sounds/` 中台球碰撞录音及其衍生音效保留 README 中 Dsw4 / Pool Sounds.ogg 的公有领域来源说明。
- `sounds/table-piano.mp3` 采用 CC BY 4.0；作者、来源及处理方式见 [sounds/MUSIC-LICENSE.md](sounds/MUSIC-LICENSE.md)。
- `sounds/xiaotang-intro.mp3`、`sounds/xiaotang-game-loop.m4a` 为用户提供的音乐，本次未授予重新许可或独立再分发权；使用者应自行取得相应授权。
- `assets/` 中图片的设计来源见 [ASSET-DESIGN.md](ASSET-DESIGN.md)；本次 MIT 代码许可不包含图片素材。

公开仓库及下载包保留游戏现有资源和许可说明，不将第三方素材改标为 MIT。代码可单独复用，部署时可按自身授权替换图片和音乐。
