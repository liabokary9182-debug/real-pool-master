# 光域台球 · 大师战术版

支持手机横屏与全屏的 Canvas 八球／九球游戏，包含分级人机对战、旋转杆法、碰库进攻和防守走位。

源码版本保留在原 layertext-studio 仓库的 `real-pool-master-20261006` 分支，与原 `main` 并列。本仓库仅承载新版的独立 GitHub Pages 站点，发布目录为本仓库根目录。原网站与旧分支保留。

## 功能

- 八球、九球、同屏双人和入门／标准／大师三级电脑对手。
- 高杆跟进、低杆拉回、左右塞；大师比较 19 种击球点并评价下一合法球的线路和走位。
- 大师试算翻袋、白球碰库勾球进攻，以及遮挡对手合法首碰线的安全球。
- 玩家和电脑使用相同的出杆、球球碰撞、库边、袋口和犯规判定。
- 原首碰圆与两条短辅助线；拖动台面瞄准、刻度尺精调、拉杆出杆与自由摆球。
- 可见横屏、全屏按钮，旋转后转换触控坐标；系统全屏取决于浏览器能力。
- 本地钢琴音乐与真实台球碰撞录音，可导入本机音频。

## 物理

在原有二维引擎上局部优化：180 Hz 固定步长，按速度增加碰撞子步，滑动摩擦 0.20g、滚动阻力 0.012g，球球恢复系数 0.94、库边 0.79、袋角 0.69。高低杆保留旋转与滑动相互作用，侧旋碰库使用带摩擦上限的切向冲量和能量约束。

普通击球速度曲线保留；开球软限幅至约 260 英寸／秒以内，默认 56% 力度和中杆。六袋口径约 100.3 mm，保留商定的 +2%；绘制、胶边碰撞与有效下沉区域共用几何。慢球进入有效下沉区域即可落袋，不依赖额外速度，不设置吸袋力。

短辅助线用于首碰方向判断，不能当作完整旋转／多库最终轨迹。物理仍是二维近似，未完整移植商业游戏、Unity PhysX 或 Pooltool 的三维模型；手机手感及大师搜索等待需真机确认。AI 选择和执行可能失误，不保证每杆成功。

## 本地运行与部署

在本目录运行：

```sh
python3 -m http.server 8765
```

访问 `http://127.0.0.1:8765/`。全部运行资源使用相对路径，游戏无需后端、第三方脚本 CDN 或 SoundCloud 播放器。本独立仓库部署目录为根目录 `/`，入口为 `index.html`，无需构建。

本仓库用于独立 GitHub Pages 发布，发布源为本仓库 main 分支的根目录。原 layertext-studio 网站及其 Pages 设置保持不动。源码版本保留在 https://github.com/liabokary9182-debug/layertext-studio/tree/real-pool-master-20261006 ，对应提交 3d79fa40061dded0294adc1cd79b6d8c76ddb755。GitHub Pages 不构成全国网络可达性保证。
