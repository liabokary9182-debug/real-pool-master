# 光域台球 · 浮光竞技馆

支持手机横屏与全屏的 Canvas 八球／九球游戏，包含分级人机对战、旋转杆法、碰库进攻和防守走位。

当前独立仓库为 `liabokary9182-debug/real-pool-master`，GitHub Pages 从 `main` 发布。网站：https://liabokary9182-debug.github.io/real-pool-master/ 。旧 `layertext-studio/real-pool-web` 不再是本项目的发布入口。

## 功能

- 八球、九球、同屏双人和入门／标准／大师三级电脑对手。
- 高杆跟进、低杆拉回、左右塞；大师比较 19 种击球点并评价下一合法球的线路和走位。
- 大师以进攻为优先：困难球比较直接进攻、翻袋与勾球；已有合法进球路线不会因低稳定性切换为藏球防守。无稳定进球方案时允许接近目标袋口的合法进攻尝试，只有没有合理攻击线路才解球或防守。
- 原创设备设计：弧影 01 球杆使用枫木、石墨黑杆尾和偏心铜弧镶嵌；澄域 C1 台呢配细字印记及暖灰金属框。
- 玩家和电脑使用相同的出杆、球球碰撞、库边、袋口和犯规判定。
- 原首碰圆与两条短辅助线；点按选方向、0.012°/像素拖动精调，刻度尺支持 0.001／0.004／0.008°/像素三档；拉杆出杆与自由摆球。
- 高分辨率画布按显示面积调整，手机 1.35–1.8 倍、桌面 1.5–2 倍；球面纹理分批更新，位置按屏幕原生刷新率绘制。
- 页面加入短翻转淡入，尊重系统减少动态效果设置。
- 手机直接进入横屏游戏，不显示方向检测或拦截提示；内置浏览器保持窄视口时自动旋转游戏画面，视口变宽时恢复正常横向布局。系统全屏取决于浏览器能力。
- 用户提供的本地欢迎音乐与对局循环音频；对局音乐交叉淡化循环，台球碰撞使用本地录音。旧 Lullaby 开关与导入音频界面已移除。
- 台呢印字和库边铭牌使用原创“澄域 C1”；袋口使用自然暗影与深色内壁。
- 欢迎背景使用全新创作的虚构竞技馆，冷色聚光灯、暗色弧形建筑，无真实赛事及赞助商标识；顶部返回上一页，结束后独立显示比分、返回主页与再来一局。
- 袋口支撑台面保持台呢蓝，实际下沉区为黑色，阴影胶边与下沉几何保持对应；大师搜索更有力的出杆及 0.95 强高低杆，在合法进球和安全走位前提下优先选择击打。
- 普通／进阶保留原准确率设置；大师改用实际输入误差和球路风险评估，不再为达到 95% 命中率重试修正出杆。贴库远台薄切会主动比较真实翻袋、勾球和安全球。

## 物理

在原有二维引擎上局部优化：180 Hz 固定步长，按速度增加碰撞子步，滑动摩擦 0.20g、滚动阻力 0.012g，球球恢复系数 0.94、库边 0.79、袋角 0.52。高低杆保留旋转与滑动相互作用，侧旋碰库使用带摩擦上限的切向冲量和能量约束。

普通击球 25% 及以上的速度曲线保留，5%～25% 增加轻推细分；开球软限幅至约 260 英寸／秒以内，默认 56% 力度和中杆。本轮按截图将球体和袋口在上一版基础上同增 5%，球径约 63.01 mm、六袋口径约 110.5 mm；绘制、胶边碰撞与有效下沉区域共用几何。慢球进入有效下沉区域即可落袋，不依赖额外速度，不设置吸袋力。袋角恢复系数改为 0.52，减少反复晃袋。

短辅助线使用实际出杆和物理子步生成，反映当前力度及旋转，在二次碰球、碰库或短线长度上限处结束；不能当作完整旋转／多库最终轨迹。物理仍是二维近似，未完整移植商业游戏、Unity PhysX 或 Pooltool 的三维模型；手机手感及大师搜索等待需真机确认。AI 选择和执行可能失误，不保证每杆成功。本轮说明见 [欢迎页与结算流程](REVIEW-20261009.md)。

## 本地运行与部署

在本目录运行：

```sh
python3 -m http.server 8765
```

访问 `http://127.0.0.1:8765/`。全部运行资源使用相对路径，游戏无需后端、第三方脚本 CDN 或 SoundCloud 播放器。部署目录为本仓库根目录，入口为 `index.html`。修改 CSS、`startup.js` 或 `landscape.js` 后必须运行 `node scripts/build-entry.cjs`，更新 `site.css` 与入口内联启动代码，再一起提交。

部署沿用独立仓库现有 GitHub Pages 配置；更新 `main` 后检查对应的 `pages build and deployment` 工作流成功，再验证线上页面与资源。具体步骤见 [发布记录](DEPLOYMENT.md)。

### 最新手感与落袋调整

台面横向或纵向滑动均可调角度，球杆方向不影响灵敏度；点按选大方向，右侧刻度尺细调，左侧拉杆击球。澄域台呢使用原创潮线印记。落袋保留入袋速度与滚动朝向后下坠，袋衬接触衰减运动，袋底播放清脆短音。左右塞正面碰库方向与强度已回归验证；大师继续优先进攻困难球。

欢迎页居中大标题，带聚光灯、缓慢球轨、浮动八球与九球，支持减少动态效果。点右侧白球弹出大白球，调整杆法与加塞后点下方“✓ 确认”；取消保留原设置。辅助线实时跟随拉杆力度并保留碰球后的短程曲线，不画碰库后的路线。

## 访问与启动（2026-10-09）

关键启动与横屏适配直接随 HTML 到达，九份样式合并成一次请求；游戏、音乐与适屏脚本独立异步加载。音乐和装饰图不阻止游戏进入。火箭位置与百分比绑定真实加载阶段，游戏和样式就绪才到 100%。引擎下载失败只重试该脚本；请求仍在等待时不会重复下载或刷新页面。加载 UI 可用 `?test=loading` 预览。

这能修复资源阻塞启动，不能保证所有网络均可访问 GitHub Pages。当前没有服务端多人会话或玩家数限制，用户对局与 AI 都在各自设备运行；若用户连 HTML 都打不开，应排查托管入口和用户网络，不能把增加前端重试当成已解决。
